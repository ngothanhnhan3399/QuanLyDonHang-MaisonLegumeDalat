BỘ FILE LOGO - MAISON LÉGUME DALAT
====================================
Danh sách file trong gói:
1. maison-legume-dalat-logo.png : Logo nền trong suốt 1024x1024px (dùng chèn vào web, hóa đơn PDF, Canva, in tem).
2. logo.svg                     : File SVG gọn nhẹ để nhúng trực tiếp vào web / GitHub.
3. favicon.ico                  : Biểu tượng trên tab trình duyệt (16px - 256px).
4. favicon-32x32.png            : Biểu tượng tab trình duyệt chuẩn PNG.
5. apple-touch-icon.png         : Biểu tượng 180x180px nền trắng tối ưu cho iPhone/iPad (Thêm vào MH chính).
6. icon-192.png & icon-512.png  : Biểu tượng chuẩn ứng dụng web (PWA / Android).

CÁCH GẮN VÀO FILE HTML (Dán vào trong thẻ <head>):
--------------------------------------------------
<link rel="icon" type="image/x-icon" href="./favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="./favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="./apple-touch-icon.png">
